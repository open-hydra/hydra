Hydra at a glance

Dedicated solvers, shared workflow, and optional cross-solver coupling

Compressible Fluid Flow

Ideal-gas Euler/Navier-Stokes, turbulence models, and reacting-flow capabilities on structured multi-block grids.

Solid Heat Conduction

Steady and transient solid conduction with multi-material support and boundary models for conjugate workflows.

Radiation Transport

Radiation transport equation for radiative heat transfer applications.

Coupled Execution

Hydra applications can coordinate multiple solvers in one run, exchanging interface quantities at coupling boundaries.

Scalable Runtime

OpenMP and MPI support across the framework and solver libraries, suitable for workstation and HPC runs.

Single Workflow

Common Hydra commands for build and execution, with solver-specific physics and documentation linked from one hub.

Start with Hydra, then choose your solver

Build a Hydra executable, run a case, and then dive into solver-level docs for detailed models and input options.

Installation guide → Quick start
terminal 
# Clone and build
$ git clone https://github.com/open-hydra/hydra.git
$ cd hydra && source bootstrap.sh
$ figaro build hydra-MF

# Run a case
$ figaro hydra-MF solve
