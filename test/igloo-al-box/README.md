# igloo-al-box — liquid aluminium burns with steam, the alumina a smoke family

IGLOO, Beckstead with the oxide cap (xi-cap 0.2, its residue left); the rest of the oxide is the smoke, born in the ICE phase `partE`. One reaction, `2 AL(L) + 3 H2O => AL2O3(L) + 3 H2` (`al-h2o.yaml`); the gas is N2 H2O H2.

Closed forms and checks: `test/mi2-checks/p30_al_smoke.py`. `INPUT/` is what ATLAS writes for `input.ini`
(`GPB ICB BCB`); `MESH/` is `test/ice-box`'s. Gate: `test/mi2-checks/p30_al_smoke_check.sh`.
