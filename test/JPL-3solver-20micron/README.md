# JPL-3solver-20micron

MOSE + ICE (`partE`) + IGLOO (`partL`) on the Chang (1980) JPL nozzle, 20 µm alumina, **same material in both
condensed phases, half the loading each** (`krho = 0.15` per phase, 0.30 in all as the single-phase cases; ATLAS
writes each phase's inlet share krho/(1 - krho_tot) = 0.15/0.70, total mass-flux ratio 0.42857 as in the single-phase
cases). Each solver reads only its own file set:

| solver | INI key | files |
|---|---|---|
| ICE   | `[ICE-Parameters] phase = partE` | `INPUT/partE-{phase.txt,properties.dat,bc.txt,ic.tec}` — bc generated by ATLAS `main` (f3=300 axis symmetry since 2026-09-25, f4=301, which ICE treats as 300), ic from ICB with the halved `krho` |
| IGLOO | `[IGLOO-General] phase = partL`  | `INPUT/partL-{phase.txt,properties.dat,bc.txt}` — bc generated by ATLAS `main` (f3=300 axis symmetry since 2026-09-26, f4=301 trap wall) |

The axis is a symmetry plane for every phase, so the two bc files are byte-identical. Each solver still reads
its own file (`[ICE-Parameters] phase`, `[IGLOO-General] phase`); that routing is gated by
`test/mi2-checks/p1_routing_checks.sh`. Every input is generated from `input.ini` by `test/mi2-checks/regen_case.sh <case> <scratch> GPB BCB ICB
[--install]` with ATLAS `main` (`10af356` or later writes the 401 record by the mixture rule over the dispersed
phases: field 1 krho/(1 - krho_tot), field 10 G, which ICE and IGLOO require); the hand-copied files of 2026-09-16 are
history.

Run: `figaro hydra-MI2 -p 4 solve` (≈ 7 min). Compare: `python3 jpl_compare.py`. Gate:
`test/mi2-checks/p18_jpl_chang_check.sh` runs the three JPL cases at 4 threads and judges them against Chang's curves.
Full loading in each phase instead: `krho`, `partE-krho` and `partL-krho` at 0.30 in `input.ini`, then
`regen_case.sh` with BCB and ICB.
