# JPL-3solver-20micron

MOSE + ICE (`partE`) + IGLOO (`partL`) on the Chang (1980) JPL nozzle, 20 µm alumina, **same material in both
condensed phases, half the loading each** (`krho = 0.17647` per phase, total mass-flux ratio 0.42857 = the
single-phase cases). Each solver reads only its own file set:

| solver | INI key | files |
|---|---|---|
| ICE   | `[ICE-Parameters] phase = partE` | `INPUT/partE-{phase.txt,properties.dat,bc.txt,ic.tec}` — bc generated by ATLAS `main` (f3=300 axis symmetry since 2026-09-25, f4=301, which ICE treats as 300), ic from ICB with the halved `krho` |
| IGLOO | `[IGLOO-General] phase = partL`  | `INPUT/partL-{phase.txt,properties.dat,bc.txt}` — bc generated by ATLAS `main` (f3=300 axis symmetry since 2026-09-26, f4=301 trap wall) |

Since both phases are mirrored at the axis (2026-09-26) the two bc files are byte-identical. Each solver still reads
its own file (`[ICE-Parameters] phase`, `[IGLOO-General] phase`); that routing is gated by
`test/mi2-checks/p1_routing_checks.sh`. Since 2026-09-18 every input is generated from `input.ini` by `test/mi2-checks/regen_case.sh <case> <scratch> GPB BCB ICB
[--install]` with ATLAS `main` (`76cd8a3` or later carries the per-phase BC payloads, the `modeling` token and the
axis override `<phase>-type = symmetry`); the hand-copied files of 2026-09-16 are history.

Run: `figaro hydra-MI2 -p 4 solve` (≈ 15 min). Compare: `python3 jpl_compare.py`.
Full double loading instead: set `krho` back to `0.30000E+00` in both bc files and restore `partE-ic.tec`
from `../JPL-Eulerian-20micron/INPUT/part-ic.tec`.
